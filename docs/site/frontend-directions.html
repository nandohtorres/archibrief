Exposure & access

Audit-log bucket allows public access ›

Critical rule result

The payments-audit-logs S3 bucket does not have Block Public Access enabled at the bucket level. Since this bucket holds transaction audit trails, an exposed listing would undermine the audit story this review is meant to support.

Recommendation: enable S3 Block Public Access on the bucket and at the account level; both are one Terraform attribute.
